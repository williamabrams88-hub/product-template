# Architecture decisions (ADRs)

One file per decision, named `NNN-title.md`, written by `/plan`. Add one line for each to `docs/decisions.md`.

## Template

```
# NNN: Title

Status: proposed | accepted | superseded by NNN
Date:

## Context
What forces the decision.

## Options considered
1. Option, and what it costs.
2. Option, and what it costs.

## Decision
What we chose and why.

## Consequences
What gets easier, what gets harder, what to revisit and when.
```
